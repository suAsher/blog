## 验证

从项目根目录运行：

```bash
python3 examples/ai-infrastructure/checks/verify.py
```

脚本只读取列出的六份生成文章，抽取各自唯一的 Python 代码块，在独立临时目录和隔离 Python 进程内运行。每篇上限 10 秒，核对精确输出、正文长度、章节清单和图解。它不接受用户指定的文章路径，不用于执行上传文档里的代码。测试输出包含最终文件 SHA256，方便检查后续内容变化。

2026-10-31 在 Python 3.9 上实测六份程序全部通过：

- 契约：两个接受、六种拒绝、输入未被修改。
- 负载：相同五次到达；有界模式完成三项拒绝两项，p95 为七；全部接收模式完成五项，p95 为十三。
- 内存：每位置 131072 字节；预留 192/192/320 MiB，第三项拒绝，剩余 128 MiB；验证容量守恒及非法输入。
- 调度：占用从七降至取消后的三，最终归零；重复取消和终态复活均拒绝。
- 可靠性：十单位总预算在九完成，七单位预算在七终止；部分输出不自动重试。单次上限与总截止点分别触发的部分输出超时均只尝试一次，保留 `partial_timeout` 原因；次数及退避窗口有效。
- 综合实验：四项提交，两项成功、一项取消、一项拒绝；全提交分母达标率 25%，成功分母达标率 50%；重复终态与时间倒退被拒绝。

这些是确定性代码验证结果，不是吞吐基准。没有执行真实 GPU、推理引擎或网络故障实验。综合账本只验证文中明确声明的异常，不自称覆盖任意事件协议的所有不合法序列。

## 官方延伸来源

以下页面在 2026-10-31 在线核对。文章使用原创算例和代码，没有复制这些来源的图像或实现；延伸页面可能持续更新，应以实际使用的软件版本为准。

- [Hugging Face：分词算法](https://huggingface.co/docs/transformers/main/tokenizer_summary)：理解 token 与字符不能互换，实际输入还需要对应模板。
- [Hugging Face：缓存策略](https://huggingface.co/docs/transformers/main/kv_cache)：核对真实模型的缓存条件，不把统一公式应用到所有结构。
- [vLLM：Paged Attention](https://docs.vllm.ai/en/stable/design/paged_attention/)：查看状态块与内核组织背景；本文没有复现其内核。
- [Google SRE：处理过载](https://sre.google/sre-book/handling-overload/)：理解资源耗尽、拒绝和余量的工程动机。
- [AWS Builders’ Library：超时、重试与退避](https://aws.amazon.com/builders-library/timeouts-retries-and-backoff-with-jitter/)：真实调用中的恢复约束；本文固定退避仅用于手算。
- [Google SRE：监控分布式系统](https://sre.google/sre-book/monitoring-distributed-systems/)：组织服务观测问题。
- [vLLM：Production Metrics](https://docs.vllm.ai/en/stable/usage/metrics/)：接入真实引擎时核对各指标定义与版本。
