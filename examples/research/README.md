# 工程研究演示资料

本目录由本次任务生成，供知识空间的导入、阅读、历史、批注与专题功能验收。全部内容、图像、情境和数字都是生成的演示材料，不是作者真实经历、生产指标或实测结果，不包含凭据、客户信息或真实环境配置。

## 导入并查看

1. 登录知识空间，打开「写作」中的「导入文档」。
2. 选择整个 `import-bundle` 文件夹，保留 `articles/`、`notes/`、`images/` 的相对路径；不要选择本 README。
3. 在预览中检查五篇文档的标题、图片匹配和重复提示。首次导入应得到四篇 Markdown、一篇 TXT；两张 PNG 仅作为配图，不会变成文章。
4. 导入后在收件箱或草稿中打开文档。检查标题以「演示 ·」开头，正文开头有生成声明，图片和代码块可以显示。
5. 发布需要阅读的文档，再从文章列表或专题工作区打开。文档中的双链使用完整演示标题；关联目标发布后可在阅读视图解析。
6. 再次导入同一文件夹可检查重复识别。需要副本时，使用界面明确提供的副本操作。

`written-article.md` 和 `experiment-template.md` 位于资料包之外，供站内编辑器写作与草稿示例使用。真实演示脚本会保留一篇已发布写作文章和一份草稿模板；它们同样明确标注为生成演示。

建议把四篇文章依次加入一个名为「演示 · 推理工程研究路线」的专题：延迟预算 → 可复现实验 → 源码证据 → 复盘手册。并排比较前两篇，可以看到假设如何映射到实验记录。

## 试用历史与批注

在延迟文章中选取这句完整文本创建批注：

> 预算是下一次实验的地图，不是这一次结果的奖状。

保存批注后刷新页面核对。在写作中把文章的一小段改成自己的演示补充，保存后查看历史与差异；恢复旧版本应产生新的当前版本。示例正文里出现的代码只打印构造记录，不会访问网络或操作集群。

## 删除演示资料

在写作列表搜索标题前缀「演示 ·」，或筛选标签「生成演示」。核对五个标题后逐篇移至垃圾箱。若确认不再需要，再在垃圾箱永久删除这些演示文档；不要批量删除自己的资料。删除相关演示专题和批注。上传配图按服务现有资源保留规则处理，删除文档不代表图片文件已被物理回收。

## 重新生成配图

在仓库根目录运行：

```sh
node scripts/generate-research-examples.mjs
node scripts/generate-research-examples.mjs --check
```

脚本只读写本示例目录，使用项目已安装的 `sharp` 将脚本内原创 SVG 渲染为 PNG；不下载图片、不读取用户照片、不请求远端服务。`--check` 只验证文件清单、演示声明、双链目标、相对配图、图表数据格式及 PNG 头。PNG 像素内容固定；不同 sharp 版本的压缩输出可能不同。
