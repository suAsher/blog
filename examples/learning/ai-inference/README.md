# AI 推理基础设施学习示例

3 章、6 篇生成演示：请求与数据、阶段与状态预算、测量与服务约束。它们展示从基础概念走到可检查实验记录的路径，不代表完整课程、作者经历或模型/GPU实测。

每篇的 Python 代码独立保存为文件即可运行，只使用标准库，不下载模型、不连接服务、不需要 GPU。所有数字都是构造值。六个代码块已经逐一执行，内置断言全部通过；正文中的预期输出与实际一致。

文章以 `[[标题]]` 形成同方向的引用环。导入正文并发布后，既可按章节阅读，也可通过现有双向链接与知识图谱回顾。
