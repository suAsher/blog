# 分布式系统 · 生成演示资料

该方向包含 3 章、6 篇 Markdown 文章，按基础、核心机制、恢复或排查实践组织。全部场景和数值都是教学构造，不是作者经历或任何机器的实测报告，也不宣称组成完整课程。

`index.json` 描述方向与章节，`.md` 文件提供可独立阅读的正文，每篇末尾以双向链接连接下一节，末节回到第一节复习。文章依然可以单独阅读、编辑和加入其他专题。

所有 Python 代码只使用标准库；每篇放进独立临时目录运行，不需要网络服务、真实账号、环境密钥或机器监控权限。每段代码已实际运行，并执行内嵌断言；模拟不具备真实服务的并发、持久化或故障保证，适用边界见正文。

正文可通过博客导入工具上传为草稿，检查后发布，再按章节加入学习路线。删除路线不应删除文章正文。
