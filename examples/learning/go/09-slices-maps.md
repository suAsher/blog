## 本节目标

选择集合时，先确认是否需要稳定顺序和存在性判断。

## 先明确你要怎样使用数据

阅读路线需要有顺序，因此适合用切片保存；根据标题查找阅读次数时，更适合使用 map。两者解决的问题不同，不应该只因为一种写起来熟悉，就把所有数据塞进去。切片允许按位置访问，map 则根据键查找对应的值。

```go
package main

import "fmt"

func main() {
    chapters := []string{"起步", "类型"}
    chapters = append(chapters, "函数")
    visits := map[string]int{"起步": 2}
    for _, chapter := range chapters {
        count, exists := visits[chapter]
        fmt.Printf("%s：次数 %d，有记录 %t\n", chapter, count, exists)
    }
}
```

## 运行后区分没有记录和零次

执行 `go run .`。第一章存在记录并且次数为二，后两章的数值是零、存在标志为 false。读取一个不存在的 map 键会得到值类型的零值；如果业务必须区分缺失和零，就使用第二个布尔返回值，而不是仅比较数值。

`append` 返回新的切片描述，因此需要接住返回值。底层数组是否重新分配取决于容量，不能把它当作固定承诺。两个切片可能引用同一个底层数组，修改其中一个可能影响另一个；需要独立数据时应明确复制，而不是仅把变量赋给另一个名字。

## 顺序与并发的边界

不要依赖遍历 map 的顺序来展示章节。若需要排序，可以先取出键、排序后逐个读取，或者像本例一样由切片控制顺序。普通 map 也不是任意并发读写的容器，等学习并发时再讨论同步保护，不要把当前示例直接复制到多个协程同时修改。
