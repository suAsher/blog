## 本节目标

理解终端、编译器和编辑器的职责，建立可验证的本机环境。

## 先分清三个角色

编辑器负责让你输入代码，终端负责启动命令，Go 工具链负责检查、编译和执行。编辑器里出现运行按钮，并不代表终端已经能找到 Go。第一步不是安装很多插件，而是确认最小路径成立：创建文件，保存内容，再从终端运行它。

在 Go 官方安装页面选择适合自己操作系统和处理器架构的稳定版本，按安装器提示操作。完成后重新打开终端，运行下面的诊断命令。这里不固定版本号，目的是观察当前机器实际使用的工具，而不是照抄某个历史截图。

```bash
go version
go env GOOS GOARCH
```

第一条输出工具链版本，第二条输出目标操作系统与架构。它们不是程序性能指标，也不包含你的业务配置。如果命令不存在，先检查安装路径和当前终端的 PATH，不要反复下载安装包。

## 用最短程序验证

把下面内容保存为一个新目录里的 `main.go`，注意不要被编辑器自动保存成 `main.go.txt`。文件名可以改变，但扩展名必须是 `.go`。

```go
package main

import "fmt"

func main() {
    fmt.Println("你好，Go")
}
```

```bash
go run main.go
```

屏幕应输出 `你好，Go`。`go run` 完成编译后执行程序；它并非逐行解释源码。第一次启动可能比之后慢，不能据此推断业务程序的运行速度。

## 试着独立完成

关闭编辑器的运行面板，仅在终端里重复执行一次。将问候语改成自己的学习目标，保存后再运行。最后故意删去一个引号，观察报错中的文件名和行号，然后修复。读懂错误位置，比把所有错误文字一次记住更有用。
