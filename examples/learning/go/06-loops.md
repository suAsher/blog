## 本节目标

理解次数、退出条件与遍历值之间的区别。

## 每个循环都要回答如何结束

Go 使用 `for` 表达循环。循环可能按次数运行，也可能持续到某个条件不成立；遍历集合时则常配合 `range`。先说清楚循环的目标和结束条件，可以避免把重复工作写成无法退出的程序。

```go
package main

import "fmt"

func main() {
    topics := []string{"工具", "类型", "函数"}
    for index, topic := range topics {
        fmt.Printf("%d. %s\n", index+1, topic)
    }
    sum := 0
    for number := 1; number <= 3; number++ {
        sum += number
    }
    fmt.Println("总和：", sum)
}
```

## 对照输出建立索引意识

执行 `go run .`，前面三行编号为一到三，最后的总和为六。切片的索引从零开始，展示给读者的编号可以加一，但访问元素时不能直接照搬展示编号。`range` 返回索引和元素值；元素值是一次赋值结果，不应把修改它误认为一定修改了原切片。

普通计数循环由初始化、继续条件和每次迭代后的动作组成。这里 `number <= 3` 允许三进入计算；如果改成小于三，结果就不一样。观察边界比背诵括号和分号更重要。Go 不要求在条件外加圆括号。

## 跳过与结束不是同一件事

`continue` 跳过本次剩余语句，然后进入下一次迭代；`break` 结束当前循环。它们在嵌套循环中的作用范围需要格外留意。若每层都依赖复杂的跳转，往往应该先把一部分工作提取为函数，而不是继续增加标签。
