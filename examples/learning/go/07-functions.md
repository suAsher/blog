## 本节目标

认识参数、返回值和职责边界。

## 一个函数最好表达一个动作

函数把一段行为命名，并通过参数接收所需的数据，通过返回值交出结果。好的拆分不是每三行就建一个函数，而是让读者能够从名字和输入输出理解它的职责。本节用温度转换作为纯计算例子：它只依赖参数，不读全局变量，也不直接操作文件。

```go
package main

import "fmt"

func celsiusToFahrenheit(celsius float64) float64 {
    return celsius*9/5 + 32
}

func main() {
    freezing := celsiusToFahrenheit(0)
    boiling := celsiusToFahrenheit(100)
    fmt.Printf("%.1f %.1f\n", freezing, boiling)
}
```

## 从两组确定输入验证

把完整代码保存到学习模块的 `main.go` 后执行 `go run .`。预期输出 `32.0 212.0`。参数类型写在名字后面，返回类型位于参数列表之后。返回语句会结束当前函数，并把值交给调用者；调用者可以保存、继续计算或者展示它。

这里参数名包含单位，避免把摄氏和华氏混淆。对于真实系统，单位往往比变量叫短还是长更重要。如果只写 `convert(value)`，读者就需要进入实现才能知道转换方向。函数签名也是文档的一部分，应当让错误使用变得更难。

## 计算与展示分开

转换函数不调用打印，因此可以在不同界面里复用，也容易写自动化测试。如果把读取终端、转换和写文件全部塞进一个函数，失败来源会更难区分。先把没有副作用的计算保留下来，再由外层决定怎样输入和输出，是初学阶段很实用的习惯。
