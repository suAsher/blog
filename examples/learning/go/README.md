## 阅读和运行

每篇代码是**独立示例**。给每篇新建一个目录并运行 `go mod init example.com/learning/exercise`，再按正文保存文件。不要将多个包含 `main` 的示例放进同一个包。测试一章需要同时保存函数文件和 `_test.go` 文件。

本机不要在含真实工作配置的目录里练习；例子不需要读取私人文档或服务器文件。代码可复制到自己的笔记中，修改后的结论应由自己运行和验证。

## 服务器演示写入

部署完成且所有者明确需要演示资料后，在**服务器内部**运行：

```bash
python3 /srv/asher-knowledge/current/deploy/seed-learning-demo.py \
  --examples /srv/asher-knowledge/current/examples/learning/go \
  --server-root /srv/asher-knowledge
```

脚本从服务器私有凭据文件在内存中登录同源 HTTPS，不向本机导出密码或会话。它使用稳定的导入请求收据创建 12 篇自己的草稿，再逐篇发布和记录进度，最后建立六章路线。已有用户文章不会被匹配更新。完成标记保存在服务器 `showcases/learning-go-v1.json`，目录 0700、文件 0600；重复执行已完成任务直接退出，不重建或覆盖手动编辑。

脚本中途停止时可重复运行；如演示稿被人工改名、撤回或修改，会停止自动发布并提示核对。不要删除标记强行重跑。若要移除演示内容，在界面删除对应路线，并将仅属于这组演示的文章移入回收站；删除路线不会删除文章。
