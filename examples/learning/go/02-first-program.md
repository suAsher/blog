## 一段程序为什么能启动

`package main` 表示这个包可以构建成可执行程序，`func main()` 是其启动入口。花括号里的语句依次执行。`import "fmt"` 引入标准库中的格式化包；调用前缀 `fmt.` 表明函数来自这个包。引入了却没使用的包会导致编译错误，这有助于尽早发现无用依赖。

模块可以理解为一组共同维护的 Go 包，以及它们依赖的版本边界。它不等于一个进程，也不是一个必须联网注册的账户。进入一个新建的空目录，初始化学习模块：

```bash
go mod init example.com/learning/hello
```

这里使用演示模块路径，不会连接这个域名。命令会创建 `go.mod`；对于这个只用标准库的小程序，不需要下载第三方包。

```go
package main

import "fmt"

func main() {
    topic := "Go 入门"
    fmt.Printf("今天学习：%s\n", topic)
    fmt.Println("先运行，再解释，再修改。")
}
```

保存为 `main.go` 后，在同一目录执行：

```bash
go fmt ./...
go run .
go build -o hello .
```

`go fmt` 调整格式，`go run .` 执行当前包，`go build` 产生名为 `hello` 的可执行文件。Windows 下可把输出名改成 `hello.exe`，再运行对应文件。代码格式由工具统一，初学阶段可以把精力留给逻辑。

## 检查你的理解

第一行输出应包含 `今天学习：Go 入门`，接着出现第二句文字。把两条输出交换位置，再观察结果。随后把变量名 `topic` 改成 `subject`，确保声明和使用一起修改。编译器会指出遗漏，不需要靠肉眼逐页排查。
