# 知识空间演进计划

基线：`d529066`。2026-10-26 已确认连续执行全部五个阶段；保留每阶段验证与独立提交，不自动推送或更新公网服务。

## 不变量

- Astro 静态页面 + TypeScript 渐进增强 + 单实例 Go 文件存储，无数据库、在线字体、CDN 或外部运行时 API。
- 工作稿与发布快照隔离、版本冲突、鉴权、Origin 检查、限流、大小预算及安全 Markdown 渲染保持有效。
- 登录公开资源使用精确白名单；不扩大匿名可读内容。新接口沿用 Go 鉴权中间件。
- 所有真实数据保留在独立数据目录；程序回滚不能用旧数据覆盖新文章。
- 浏览器测试使用临时本地私有环境和虚构语料，不读取真实文档或生产凭据。

## 1. 视觉与动效

先格式化样式并保留层叠顺序；建立完整深浅色令牌和组件样式。OGL 首页主视觉、GSAP/ScrollTrigger 与 Lenis 按需加载，保留 CSS 星轨、原生指针及正常导航。减少动画、低性能、离屏、隐藏、WebGL 失败均降级/暂停。阅读和写作保持原生滚动。

增强现有跨文档转场；不直接启用 ClientRouter。补充真实阅读封面、文字优先显示及图片渐进加载。重绘首页、列表、书架、关于、404、登录。逐子功能提交，回滚增强层无需改数据。

## 2. 每日入口

复用文档工作稿保存随手记；加入今日回顾、周年文章、最近编辑、草稿和真实写作活动。新增字段均可选：`series`、`maturity`、`related`；`status` 继续表示发布生命周期。缺省字段保留，显式空值清除。

热力图只统计新增的真实活动，不伪造历史。全局提供随手记按钮和命令动作；默认使用可配置替代组合键，避免隐私窗口快捷键冲突。

## 3. 知识连接

服务端 Markdown AST 解析 Wiki 链接，排除代码块和行内代码。处理别名、重名、改名、未创建目标，使用稳定 ID 维护关系。发布反链与图谱不泄露工作稿关系。派生链接索引可重建、有容量预算。图谱最多 300 个节点，提供键盘列表、缩放拖动与减少动画静态布局。

## 4. PWA、同步与回流

可安装应用壳与私有离线内容分开。Service Worker 不缓存登录、认证、API 或受保护文档响应。私文仅由用户主动保存为加密本地发布快照，独立口令解锁，退出清理/锁定，不保存服务器密码。离线不能即时感知远端撤销，界面必须明确说明。

服务端阅读/收藏 JSON 使用原子写、版本检查、合并与预算。保留旧版 JSON 导入/导出、本地缓存及离线待同步操作。同步节流，不信任设备时钟直接覆盖新状态。加入 1/3/7/30 天复习回访。

## 5. 文档与验收

更新快捷键、内容模型、链接规则、离线边界、备份/迁移/部署说明。使用受控演示语料更新桌面/平板/手机、深浅主题截图。

每阶段依次执行 `npm run check`、`npm test`、`npm run test:e2e`、`npm run build`、`auth/` 内 `go test ./...`。另运行覆盖率、依赖审计、无障碍检查及固定条件 Lighthouse。报告真实结果、跳过项和环境限制，不把历史成绩作为新验收。

Lighthouse 目标：性能/无障碍/最佳实践均 ≥90，首页 LCP <2.5 秒；固定移动节流条件至少三次冷启动，记录中位数与最差值。

## 数据兼容和回滚

新增元数据必须覆盖导入、导出、预览、列表、搜索和发布深拷贝。先兼容后端，再更新前端。新增状态与活动文件纳入备份。

写入新元数据后，旧后端再次保存可能丢失未知字段，因此后端回滚需兼容桥接或只读模式；不能宣称任意降级无损。派生索引可以删除重建，正文和用户状态不能作为缓存清理。
