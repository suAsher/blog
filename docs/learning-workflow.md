# 从资料到一条可以实践的学习路线

这一轮把已有导入、阅读和写作连接起来。仍使用 Astro、TypeScript、Go 与本地文件存储，没有增加运行时依赖、数据库或在线服务。所有正式文档与路线仍需登录访问。

## 目标、先修与实践

「路线」页可以填写学习目标和先修要求；每章可补充本章目标与实践任务。书本式入口、章节地图与可折叠目录帮助浏览，文章正文继续使用原有阅读布局。

阅读进度与实践进度分开统计。读完文章只影响已读记录，完成实践需要主动点击「我已完成这项实践」，可以撤销。修改实践任务会清除该章之前的完成标记。保存使用当前路线版本；另一设备已经更新时会提示先读取最新路线，再重新确认，不会自动覆盖。

路线上可以保留草稿和暂不可用引用，完成比例不会把不可读文档当作已掌握知识。目标与先修说明均为普通内容，不预设技术领域。

## 导入文件夹并编排

1. 在写作空间选择 Markdown、TXT 与配图，按既有预检处理重复、更新和缺图。
2. 确认导入后，在报告中选择「编排为学习路线」。也可以重新打开最近导入报告继续。
3. 根据原目录建议章节，修改名称，调整章节和文章顺序，为每篇选择归属。选择同一章节可合并；选择「不加入本路线」只排除目录引用，文档仍保留。
4. 点击「确认创建学习路线」。创建的是目录，导入草稿仍需预览和主动发布。

编排只使用报告中已确认创建/更新且当前仍存在的文档；跳过项、无法核对的标识、缺图文档和垃圾箱内容不会自动加入。每条路线最多 30 章、300 篇引用；空章不在本次导入编排中保存。可在常规路线编辑器中创建待补充空章。

同一导入报告关联一个持久创建标识。网络中断后重试或重新打开报告，会先读取已创建的路线；不会重复创建或覆盖后续人工编排。发现已有路线时提供打开入口。要撤销编排，可在路线页删除该目录，原文章和图片不受影响。

## 写作模板与教学实验

「从模板新建」提供空白文档、循序教程、原理解读、排错记录与随用速查。模板创建新的普通 Markdown 草稿，先保存当前编辑；保存失败时不会丢弃原文。提示句需要改成自己的内容，不包含虚构的个人经历或生产结论。

编辑器「教学实验」允许选择推理排队、Go 请求或网络诊断模型，修改标题并使用真实阅读组件预览，最后插入光标位置。导出的内容仍是 `explore` JSON 围栏，模型和参数由本站受控组件解释，不执行文章提供的脚本。每篇最多增强三个实验，其他定义保留原文。完整语法见 [交互内容](interactive-content.md)。

## 把批注变成问题卡

在正式文章里保存批注，再选择「制作问题卡」，写下希望日后能够独立回答的问题。解释默认带入摘录与批注，可以修改；保存后产生新的随手记草稿，并关联原文与批注位置。

问题卡用严格的 `recall` JSON 围栏保存，阅读时先显示问题，点击「展开解释」查看答案。来源只允许本站正式文章/批注地址；HTML 按普通文字显示。每张问题最多 400 字、解释 4000 字、定义 12 KiB，每篇最多增强十张。展开答案不会改变相邻正文批注的位置。

问题卡草稿需要主动发布；发布后可以在阅读页加入已有的 1/3/7/30 天文章回顾。调度单位仍是这篇笔记，没有新增一套卡片状态或后台推送。离线、同步冲突、退出清理继续遵循 [原有规则](offline-and-sync.md)。

## 阅读加载与降级

正式文章先显示标题、正文与基础阅读控件，再按需加载代码高亮。高亮未能在 1.5 秒内就绪或加载失败时，代码保留可阅读、可复制的原文，批注照常初始化。该页面后续不再应用迟到的高亮，以免改写已经建立批注锚点的文本节点。重新打开文章时可以再次尝试增强。

## 深度示范内容

[AI 基础设施内容包](../examples/ai-infrastructure/README.md)提供六篇原创生成长文，与已有推理导读组成七章主线：请求全景、契约、负载、资源预算、任务退出、超时重试、综合实验。文章包含离线可运行代码、边界断言、图解和实践交付物。它们不代表真实 GPU 测量或作者经历；旧基础文章继续保留为补充阅读。

## 数据、兼容与部署

新增可选字段均保存在原 `data/content/state/learning.json`，schemaVersion 仍为 1：

| 范围 | 字段 | 预算 |
| --- | --- | --- |
| 路线 | `objectives`、`prerequisites` | 每项最多 8 条，每条 240 字 |
| 章节 | `goal` | 800 字 |
| 章节 | `exercise` | 2000 字 |
| 章节 | `practiced` | 布尔值，与已读独立 |
| 路线 | `creationKey` | 最多 80 个限定字符的可选创建标识，创建后不可修改 |

旧记录不需要迁移。旧客户端更新省略元数据时，服务端按章节 ID 保留；显式空数组、空字符串或 false 用于清除，null 与未知字段拒绝。新功能仍经过既有鉴权、同源检查、限流、128 KiB 请求和 8 MiB 路线文件预算。

先部署新 Go 服务，再部署界面。写入新字段后，旧后端的严格解码无法识别这些字段；回滚界面应保留新后端，不能直接降级程序并覆盖数据。备份整个 `data/content/` 与运维收据即可覆盖正文、批注、问题卡、路线与进度。恢复前核对备份之后的新编辑，不能用旧备份直接覆盖持续使用中的内容。

验证环境、测试范围和本轮截图记录见 [学习路线与写作工作流验收](qa/learning-v2/README.md)。
