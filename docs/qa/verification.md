## 内容与写作

- 新建、编辑、自动保存、刷新恢复、Markdown 预览及发布。
- 工作稿修改不影响线上发布快照，重新发布后才切换。
- 标题、摘要、正文全文搜索，内容生成的标签/分类筛选；草稿不进入阅读搜索。
- 真实文章的代码高亮/复制、表格、图片、目录、进度、收藏、专注模式及书架。
- Markdown、TXT、配图批量导入；真实文件夹选择保留相对路径；缺图报告；导入先成为草稿。
- Markdown 与图片 ZIP 导出；Go 测试覆盖再导入、中文/空格/百分号路径。
- 独立浏览器能读取服务器文档；垃圾箱、恢复与永久删除。
- 匿名保护、精确 Origin 校验、版本冲突、恶意文件、路径穿越、符号链接、磁盘预留防护。
- 键盘与移动布局。补充 mock 检查验证连续选图不会覆盖正在上传的图片、上传失败阻止发布与退出；不计入公网 120 项。

容器重建使用同一正式二进制及运行镜像，在独立临时容器、临时数据目录和虚构 QA 账号下执行，未重启正式服务。浏览器测试只清理自己创建的 QA 文档，未读取或导入用户本机文档。

## 阅读与登录回归

- 首页、列表、书架、显式示例模式、空状态及真实 404。
- 全文搜索、组合筛选、URL 恢复、返回导航；脚本延迟时仍保留来源条件。
- Ctrl/Cmd+K、Esc、F 专注阅读，输入不误触快捷键。
- 收藏、已读、继续阅读、跨标签更新、记录导入导出及存储不可用降级。
- 深浅主题、减少动画、无横向溢出、无第三方内容请求。
- 匿名整站保护、真实登录与安全回跳、错误重试、密码显示、记住登录。
- 退出撤销令牌、后退重新登录、保留本地书架与主题；上下文隔离、CSRF 和恶意跳转拒绝。

## 部署与限制

云端 Nginx、Caddy、Go 服务实际运行，持久卷与只读程序挂载已检查。已验证正式 IP TLS 证书信任链、无 SNI 握手、网关重启后证书加载、公开入口和匿名保护。更新保留内容卷与旧版本。通用步骤见 [部署指南](../deployment.md)与 [内容指南](../content-guide.md)。
