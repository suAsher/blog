# 每日入口与随手记

首页的今日面板使用已登录账号的真实文档。写作、回顾和继续阅读都复用原有文档 ID、工作稿与发布快照；不会创建第二套正文存储。

## 捕捉一个想法

在首页输入一句话，或从全局随手记入口打开记录窗口。`Ctrl/Cmd + Enter` 保存为随手记草稿；保存成功后可进入完整编辑器继续整理。失败时保留输入并允许重试，不能把网络失败显示成保存成功。

全局默认快捷键使用 `Ctrl/Cmd + Alt + N`。`Ctrl/Cmd + Shift + N` 与浏览器无痕窗口冲突，因此不能保证网页截获。触屏设备始终提供可点击的入口；组合键不应成为唯一入口。命令面板 `Ctrl/Cmd + K` 也能进入写作与记录。

随手记仍是普通的私有工作稿。发布前不会出现在正式阅读列表、回顾文章或搜索结果里；可在写作空间改为文章，发布过程不需要重建网站。

## 内容的两个状态维度

发布生命周期维持原有 `status`：`draft`、`published`、`trash`。成长状态是独立的可选字段，不能代替发布权限。

| 字段 | 值与默认 | 用途 |
| --- | --- | --- |
| `kind` | `article` / `note`；旧文档默认 `article` | 文章与随手记使用同一存储和发布流程 |
| `maturity` | 空 / `growing` / `evergreen` | 可选的成长中、常青标记 |
| `series` | 可选，最多 100 字 | 内容自定义系列，没有预设技术分类 |
| `related` | 可选，最多 32 个文档 ID | 稳定关联，后续知识连接界面以标题展示 |

导入和导出的 Markdown frontmatter 保留这些属性。旧客户端更新时省略新字段会保留现值；显式空字符串或空数组用于清空，`null` 和未知字段会被拒绝。

## 活动热力图的统计口径

- 一格表示一天，数值是当天有活动的不同文档数量，不是按键次数或保存次数。
- 非空正文创建、正文发生实质变化并成功保存时记录活动；重复自动保存、仅发布、撤回或移入垃圾箱不计。
- 导入非空文档属于当天的创建活动，不会把 frontmatter 中的历史日期当成过去的写作记录。
- 每篇保留最多 400 个 UTC 日的活动首末时间；面板显示配置时区最近 366 日。默认时区为 `Asia/Shanghai`，可通过 `CONTENT_TIMEZONE` 设置有效 IANA 时区。
- 旧文档不补造历史。开始日期表示现存可用活动的起点，界面明确历史记录不完整。
- 垃圾箱中的文档仍计入活动；永久删除会移除该文档的活动，因此历史格数和连续天数可能随永久删除变化。

活动与正文在同一份文档记录内原子保存。磁盘写入失败时两者都不会被当作成功；备份整个 `data/content/` 即包含活动。

## 回顾与回流

随机回顾和往年今日只读取已发布快照。往年今日按文章日期的月日匹配，并排除当年；没有匹配时显示真实空状态。最近编辑和待完成草稿仅对登录用户可见。

现阶段继续阅读沿用浏览器状态。跨设备同步与复习计划接入后，相关规则以离线和同步说明为准。

## 更新与回滚

先更新兼容后端，再更新界面。新格式可以读取旧文档，但旧二进制再次保存时可能丢弃它不认识的新字段；不能在使用新字段后直接降级旧后端继续写作。需要回滚时保留现有数据、停写并验证兼容性，不能恢复旧内容备份覆盖新文章。
